# KG Branch

## 개요

`KG` 브랜치는 AI 딥페이크 헌터스 프로젝트의 **지식그래프 생성 모듈**을 담당한다.

딥보이스 탐지 모델이 출력한 결과를 기반으로 통화 정보, 등록 음성, 비교 음성, 탐지 구간, 위험도, 관측 근거, 사용자 대응 행동을 하나의 지식그래프 JSON으로 변환한다.

이를 통해 단순한 탐지 점수만 제공하는 것이 아니라, 사용자가 **왜 위험한지**, **어느 구간이 의심되는지**, **무엇을 해야 하는지**를 구조적으로 확인할 수 있도록 한다.

---

## 주요 기능

- 딥보이스 탐지 결과 정규화
- 위험도 자동 판단
- 의심 구간 및 관측 근거 생성
- 사용자 대응 행동 생성
- 지식그래프 노드/엣지 생성
- LLM 기반 한국어 요약 문장 생성
- 앱 또는 서버에서 사용할 수 있는 graph JSON 저장

---

## 지식그래프 구성 요소

KG 모듈은 딥보이스 탐지 결과를 단순한 수치가 아니라, 여러 개의 의미 있는 노드와 관계로 변환한다.

생성되는 지식그래프에는 다음과 같은 정보가 포함된다.

| 구성 요소 | 설명 |
|---|---|
| `Call` | 현재 분석 대상 통화 정보 |
| `UserVoice` | 사용자가 사전에 등록한 기준 음성 |
| `ComparisonVoice` | 현재 통화에서 비교되는 음성 |
| `CallSegment` | 통화 중 분석된 음성 구간 |
| `DetectedPeriod` | 딥보이스가 의심되는 시간 구간 |
| `SpoofAssessment` | 최종 위험도 및 confidence 판단 결과 |
| `ObservedIssue` | 위험하다고 판단한 근거 |
| `UserAction` | 사용자에게 추천되는 대응 행동 |

이 구조를 통해 앱은 단순히 `위험도: danger`만 보여주는 것이 아니라, 위험 판단의 근거와 대응 방법까지 함께 제공할 수 있다.
