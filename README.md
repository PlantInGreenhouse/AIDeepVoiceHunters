# AI Hack Camp 2026 - AI 딥페이크 헌터스

## 아이디어 요약

보이스피싱은 더 이상 낯선 번호의 문제가 아니라, 가족이나 지인처럼 익숙한 목소리를 흉내 내는 사칭형 범죄로 진화하고 있다.

본 아이디어는 가까운 사람들의 음성을 사전에 등록해 실제 지인의 음성을 판별하는 신뢰 기준, 즉 **“목소리 신분증”** 으로 활용한다.

실제 통화 시 현재 음성과 등록 음성을 실시간으로 비교하고, 의심 상황에서는 재확인 연결과 보호자 알림을 제공함으로써 피해를 사전에 차단하는 **예방형 디지털 안전 서비스**를 제안한다.

소규모 가족·지인 단위부터 쉽게 적용할 수 있으며, 향후 고령층 등 취약계층 보호 서비스로 확장할 수 있다.

## 프로젝트 개요

**AI 딥페이크 헌터스**는 등록된 기준 음성과 현재 통화 음성을 비교하여 딥보이스 또는 사칭 음성 여부를 탐지하고, 그 결과를 사용자에게 이해하기 쉬운 위험도와 설명 형태로 제공하는 서비스이다.

전체 시스템은 크게 다음 세 단계로 구성된다.

1. **딥보이스 탐지 모델**
   - 등록 음성과 현재 음성을 비교
   - 음성 위조 가능성 및 의심 구간 탐지

2. **지식그래프 생성**
   - 모델 탐지 결과를 구조화된 그래프 데이터로 변환
   - 위험도, 탐지 구간, 대응 행동 등을 노드와 관계로 표현

3. **모바일 앱 서비스**
   - 사용자가 음성을 등록하고 분석 결과를 확인
   - 위험 점수, 요약 설명, 의심 구간 등을 시각적으로 제공

## Branch 구조

현재 프로젝트는 기능별로 브랜치를 분리하여 관리한다.

| Branch | 역할 | 설명 |
|---|---|---|
| `main` | 기본 브랜치 | 프로젝트 기본 저장소 브랜치 |
| `AAIST` | 딥보이스 탐지 모델 | AASIST 기반 음성 위조 탐지 모델 및 KG 연동 코드 |

| `BE` | 백엔드 | 서버/API 관련 작업 브랜치 |
| `KG` | 지식그래프 | 탐지 결과를 지식그래프 JSON으로 변환하는 모듈 |

## AAIST Branch

`AAIST` 브랜치는 딥보이스 탐지 모델 구현을 담당한다.

이 브랜치에는 AASIST 기반 음성 위조 탐지 모델 코드가 포함되어 있으며, 현재 음성과 등록된 기준 음성을 비교해 딥보이스 가능성을 계산한다.

주요 역할은 다음과 같다.

- 음성 파일 입력 처리
- 기준 음성과 비교 음성 간의 위조 가능성 탐지
- 탐지 확률 및 의심 구간 산출
- 탐지 결과를 KG 모듈로 전달
- 최종적으로 모델 결과와 지식그래프 생성을 연결

주요 구성은 다음과 같다.

```text
AAIST
├── CLSModel/          # AASIST 기반 딥보이스 탐지 모델
├── KG/                # KG 생성 모듈 연동
├── main.py            # FastAPI 기반 분석 서버 코드
└── run_cls_kg.py      # 모델 추론 결과와 KG 생성 파이프라인 연결
