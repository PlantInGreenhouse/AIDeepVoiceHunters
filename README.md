# AI Hack Camp 2026 - AI 딥페이크 헌터스

## 아이디어 요약

보이스피싱은 더 이상 낯선 번호의 문제가 아니라, 가족이나 지인처럼 익숙한 목소리를 흉내 내는 사칭형 범죄로 진화하고 있다.

본 아이디어는 가까운 사람들의 음성을 사전에 등록해 실제 지인의 음성을 판별하는 신뢰 기준, 즉 **“목소리 신분증”** 으로 활용한다.

이를 실제 통화 시 현재 음성과 등록 음성을 실시간으로 비교하고, 의심 상황에서는 재확인 연결과 보호자 알림을 제공함으로써 피해를 사전에 차단하는 **예방형 디지털 안전 서비스**를 제안한다.

소규모 가족·지인 단위부터 쉽게 적용할 수 있으며, 향후 고령층 등 취약계층 보호 서비스로 확장할 수 있다.

---

## 프로젝트 개요

**AI 딥페이크 헌터스**는 등록된 기준 음성과 현재 통화 음성을 비교하여 딥보이스 또는 사칭 음성 여부를 탐지하고, 그 결과를 사용자가 이해할 수 있는 위험도와 설명 형태로 제공하는 서비스이다.

전체 시스템은 다음 세 단계로 구성된다.

1. **딥보이스 탐지 모델**
   - 등록 음성과 현재 음성 비교
   - 딥보이스 가능성 및 위험도 산출

2. **지식그래프 생성**
   - 탐지 결과를 구조화된 그래프 데이터로 변환
   - 위험도, 신뢰도, 의심 구간, 대응 행동을 노드와 관계로 표현

3. **모바일 앱 서비스**
   - 사용자에게 분석 결과 제공
   - 위험 요약, 의심 구간, 대응 행동을 화면에 표시

## Branch 구조

현재 프로젝트는 기능별로 브랜치를 분리하여 관리한다.

| Branch | 역할 | 설명 |
|---|---|---|
| `main` | 기본 브랜치 | 프로젝트 기본 저장소 브랜치 |
| `AAIST` | 딥보이스 탐지 모델 | AASIST 기반 음성 위조 탐지 모델 및 분석 서버 구현 |

## AAIST Branch

`AAIST` 브랜치는 딥보이스 탐지 모델 구현을 담당한다.

이 브랜치에는 AASIST 기반 음성 위조 탐지 모델 코드가 포함되어 있으며, 등록된 기준 음성과 현재 통화 음성을 비교해 딥보이스 가능성을 계산한다.

주요 역할은 다음과 같다.

- 음성 파일 입력 처리
- 등록 음성과 현재 음성 비교
- 딥보이스 의심 여부 탐지
- confidence 및 위험도 산출
- FastAPI 기반 분석 서버 제공
- 탐지 결과를 KG 생성 파이프라인과 연동

---

## App Branch

`App` 브랜치는 사용자가 실제로 서비스를 이용하는 모바일 애플리케이션 구현을 담당한다.

React Native 기반으로 구현되어 있으며, 앱은 FastAPI 서버와 연결되어 음성 분석 요청을 보내고 분석 결과를 받아온다.

주요 역할은 다음과 같다.

- 모바일 앱 UI 구현
- 음성 등록 및 분석 요청 인터페이스 제공
- FastAPI 서버와의 연동
- 분석 결과 시각화
- 위험도, 요약 설명, 의심 구간 정보 표시

---

## KG Branch

`KG` 브랜치는 딥보이스 탐지 모델의 출력 결과를 지식그래프 형태로 변환하는 단계를 담당한다.

단순히 모델이 `danger`, `confidence`, `spoofProbability` 같은 값을 출력하는 것에서 끝나면, 사용자는 “왜 위험한지”를 이해하기 어렵다.  
따라서 KG 모듈은 탐지 결과를 노드와 관계로 구조화하여, 위험 판단의 근거를 설명 가능한 데이터 형태로 만든다.

- 통화 정보
- 등록된 기준 음성
- 현재 통화 음성
- 음성 비교 결과
- 딥보이스 의심 점수
- 위험도 판단
- 의심 구간
- 사용자 대응 행동

주요 역할은 다음과 같다.

- 딥보이스 탐지 결과 JSON 입력
- 모델 출력값을 지식그래프 노드와 엣지로 변환
- 위험도, confidence, similarity, spoof probability 구조화
- 사용자에게 보여줄 설명 정보 생성
- 앱 또는 서버에서 활용 가능한 graph JSON 생성

KG 브랜치의 주요 구성은 다음과 같다.

```text
KG
├── data/                         # 입력 및 출력 데이터 저장
├── src/                          # 지식그래프 생성 관련 소스 코드
├── detection_output_spec.md      # 딥보이스 탐지 모델 출력 형식 정의
├── dummy.json                    # 테스트용 예시 데이터
└── run_pipeline.py               # 지식그래프 생성 파이프라인 실행 코드
