# App Branch

## 개요

`App` 브랜치는 AI 딥페이크 헌터스 프로젝트의 **모바일 애플리케이션**을 담당한다.

React Native와 Expo를 기반으로 구현되어 있으며, 사용자가 가족 또는 지인의 목소리를 등록하고, 의심스러운 통화 음성을 분석하여 딥보이스 위험도를 확인할 수 있도록 한다.

앱은 FastAPI 서버와 연동되어 등록 음성과 통화 음성을 전송하고, 서버에서 반환한 분석 결과를 사용자에게 위험 점수, 요약 설명, 의심 지점 형태로 보여준다.

---

## 주요 기능

- 가족 또는 지인 음성 등록
- 5초 음성 녹음 기능
- 등록된 가족 목록 관리
- 통화 상대 선택
- 딥보이스 분석 서버와 연동
- 위험도 점수 시각화
- 분석 결과 보고서 제공
- 보호자 알림 메시지 생성

## 프로젝트 구조

```text
APP
├── assets/              # 앱에서 사용하는 음성 및 이미지 리소스
├── App.js               # 앱 메인 화면 및 주요 로직
├── app.json             # Expo 앱 설정
├── index.js             # 앱 진입점
├── package.json         # 의존성 및 실행 스크립트
└── package-lock.json    # 패키지 lock 파일
