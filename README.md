# AAIST Branch

## 개요

`AAIST` 브랜치는 AI 딥페이크 헌터스 프로젝트의 **딥보이스 탐지 모델 및 분석 서버**를 담당한다.

등록된 기준 음성과 현재 통화 음성을 비교하여 딥보이스 의심 여부를 판단하고, 탐지 결과를 지식그래프 생성 모듈과 연결한다. 최종 결과는 앱에서 사용할 수 있도록 위험 점수, 요약 설명, 의심 구간 정보 형태로 반환된다.

> Branch 이름은 `AAIST`이지만, 실제 모델 구현은 **AASIST 기반 딥보이스 탐지 모델**을 사용한다.

---

## 주요 기능

- 기준 음성과 비교 음성 업로드
- `.m4a` 음성 파일을 `.flac` 형식으로 변환
- AASIST 기반 딥보이스 탐지 수행
- 위조 가능성 confidence 산출
- 의심 음성 구간 탐지
- 탐지 결과를 KG 생성 파이프라인과 연동
- FastAPI 서버를 통해 앱에 분석 결과 제공
